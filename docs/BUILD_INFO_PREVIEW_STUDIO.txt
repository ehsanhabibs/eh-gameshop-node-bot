Version 1.1.3 changes:
- Corrected Link Profile flow: Stock ID context -> Select Existing Profile OR Create New Profile + Link Customer.
- Existing-profile linking keeps the stored Profile Name and PIN unchanged.
- New-profile linking collects Profile Name, PIN, Customer Name and Customer Expiry Date.
- Removed Telegram ID from this Link Profile flow; named customer links are stored separately using customerLinked=true.
- Existing occupied/reserved profiles cannot be overwritten; customer history remains protected.
- Name-only linked profiles are excluded from reseller auto-allocation and manual order assignment until their expiry is processed.
- Stock Rich Message profile customer labels use normal (non-italic) text.
- Added unit tests for both link paths and overwrite protection.
- Telegram /linkcustomer entry now opens the Mini App flow instead of requesting a Telegram ID.
- Name-only linked profiles are protected from deletion and counted as assigned/running.

- Reseller Active/Inactive and Credit On/Off changes edit the existing welcome/profile Rich Message.
- Reseller due-clearance Admin and reseller messages update in place on Confirm/Reject.
